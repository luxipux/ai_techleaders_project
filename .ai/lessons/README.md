# Lesson files

One file per lesson: `YYYY-MM-DD-slug.md` (date = when learned; slug is lowercase kebab-case). Every lesson must be indexed in [../lessons.md](../lessons.md).

## Template

```markdown
# <Short title>

## Context
<What task/bug/situation surfaced this>

## Finding
<Root cause or what was learned>

## Lesson / How to apply
<Concrete guidance for future work>

Related: <run journal, spec, or file links>
```

Keep lessons short, specific and actionable.
